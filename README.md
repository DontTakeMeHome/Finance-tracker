# This project is a finance tracker. It will continue to be developed further, and I also plan to create a finance tracker program in the future (for Windows, Linux, and Android, but at minimum for Desktop).
⠀
The "Finance Tracker" is launched via the console.
⠀
**How to run on Linux:**
⠀
1. Go to the "Releases" tab and install "finance." Then open the terminal and enter the following lines:
⠀
```
cd "here write the folder where you installed the file"
chmod +x finance
./finance
```
⠀
2. If you don't want to install the file for whatever reason, then install "Source code (tar.gz)" from the same tab. It contains "finance.py." After installing, open the terminal and write:
⠀
```
cd "here write the folder where you installed the file"
python finance.py
```
⠀
I don't really understand how to run it on Windows, but try downloading the ".zip" file, extracting it, and running it through the console using roughly the same logic. Later I'll set up a virtual machine and test it there, and compile an ".exe" at the same time.
⠀
**COMMANDS:**
⠀
1. Add a transaction to the income table:
⠀
```
python finance.py add income «amount» «category» «description (if needed)»
```
⠀
2. Add a transaction to the expense table:
⠀
```
python finance.py add expense «amount» «category» «description (if needed)»
```
⠀
(quotation marks are not needed anywhere!)
⠀
3. View the income table:
⠀
```
python finance.py list income
```
⠀
4. View the expense table:
⠀
```
python finance.py list expense
```
⠀
**A BIT ABOUT THE PROJECT'S FUTURE:**
⠀
I understand that the project isn't perfect, but it will keep improving in the future. What I want to do:
⠀
1. Add the ability to modify and delete transactions in the tables.
2. Improve the syntax so it isn't so complicated and long.
3. Properly set up the color palette, since it doesn't quite work the way it was intended.
4. Make a menu that lists all available commands, or make a menu similar to this project: https://github.com/Sergeydigl3/zapret-discord-youtube-linux
5. Create programs, since using the console for a finance tracker in 2026 is very strange.
6. Add localization.
⠀
I might add something else as well. Stay tuned for updates! Good luck to everyone.
